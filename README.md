Enterprise ERP Systemنظام متكامل لإدارة الموارد المؤسسية (ERP) مبني باستخدام PHP 8 وفق معمارية التصميم الموجه بالمجال (DDD) والتصميم المعماري النظيف (Clean Architecture).🏢 الموديولات (Modules)يدعم النظام بنية मल्टी-تينانت (Multi-Tenant) ويحتوي على الموديولات التالية:المحاسبة المالية (Accounting)الخزانة والمدفوعات (Treasury)المبيعات والفواتير (Sales)المشتريات والموردين (Purchasing)نقاط البيع (POS)إدارة المشاريع (Projects)سلاسل الإمداد (Supply Chain)الأمان والسياسات (Security)🚀 متطلبات التشغيلPHP >= 8.1MySQL >= 8.0 أو MariaDBComposer📦 التثبيتقم بتثبيت الحزم:composer install
انسخ ملف الإعدادات:cp .env.example .env
قم بتشغيل السيدر (Seeders) لتجهيز شجرة الحسابات والبيانات الأساسية.🧪 الاختبارات (Testing)لتشغيل اختبارات الوحدة والتكامل:composer test
